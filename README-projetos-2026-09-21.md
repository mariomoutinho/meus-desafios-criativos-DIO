# Dois exercícios de automação com n8n e IA

Estes experimentos foram propostos para explorar como escolhas de requisitos mudam uma automação. Cada pasta contém um workflow manual importável, dados fictícios, documentação e uma postagem para o fórum.

- [Conflitos de agenda](conflitos-de-agenda/README.md): identificar sobreposições reais entre compromissos.
- [Prazos e prioridades](prazos-e-prioridades/README.md): separar tarefas abertas por prazo e preservar as concluídas.

Para conferir a lógica localmente, execute `node verificar.js` na raiz deste conjunto. Os testes executam o JavaScript dos nodes em um ambiente simulado; ainda é necessário confirmar a importação e a execução em uma instância n8n.
